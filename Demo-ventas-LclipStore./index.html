# PHŌNE - Landing Page Premium & Orientada a Conversión (Meta Ads) Esta es una landing page de alta gama desarrollada específicamente para tráfico proveniente de **Meta Ads**, orientada a maximizar la tasa de conversión mediante una propuesta visual confiable, moderna, minimalista y de precio ultra competitivo para celulares Apple iPhone y Samsung en Argentina. --- ## 📁 Estructura del Proyecto ``` phone-landing-page/ ├── index.html # Estructura semántica HTML5 orientada a conversión ├── styles.css # Sistema de diseño CSS modular (Variables CSS, Responsive Mobile-First, Dark Luxury) ├── script.js # Lógica interactiva (Filtros, Menú Mobile, Modal de WhatsApp, Scroll) ├── README.md # Guía completa de uso, despliegue y personalización └── assets/ # Renders de productos en alta resolución ├── hero-phones.png # Composición principal para el Hero ├── iphone-17.png # Render iPhone 17 ├── iphone-17-pro.png # Render iPhone 17 Pro ├── iphone-17-promax.png# Render iPhone 17 Pro Max └── samsung-a57.png # Render Samsung Galaxy A57 ``` --- ## 🚀 1. Cómo Ejecutar Localmente ### Opción A: Abrir directamente en el navegador (Sin dependencias) 1. Navegá a la carpeta `phone-landing-page`. 2. Hacé doble clic sobre `index.html` (o abrile con Chrome, Edge, Firefox, Safari). 3. ¡Listo! Todo funciona sin necesidad de servidores o compilación. ### Opción B: Ejecutar con un servidor local de desarrollo (Recomendado para testing) Podés usar cualquier extensión como **Live Server** en VS Code o ejecutar por consola: ```bash # Con npx serve npx -y serve . # O con python python -m http.server 8000 ``` Luego abrí `http://localhost:8000` en tu navegador. --- ## 🌐 2. Cómo Subirlo a GitHub Pages (Paso a Paso) Para publicar la página gratis en internet con HTTPS en menos de 3 minutos: 1. **Crear un repositorio en GitHub**: - Ingresá a [GitHub](https://github.com/) y creá un nuevo repositorio público (ejemplo: `phone-store-landing`). 2. **Inicializar y subir el código desde tu terminal**: ```bash cd C:\Users\Administrador\.gemini\antigravity\scratch\phone-landing-page git init git add . git commit -m "Initial commit - PHŌNE High Conversion Landing Page" git branch -M main git remote add origin https://github.com/TU_USUARIO/phone-store-landing.git git push -u origin main ``` 3. **Activar GitHub Pages**: - Ingresá a tu repositorio en GitHub -> **Settings** -> **Pages**. - En **Source**, seleccioná la rama `main` y la carpeta `/ (root)`. - Hacé clic en **Save**. - En 1-2 minutos la web estará en vivo en: `https://TU_USUARIO.github.io/phone-store-landing/` --- ## ✏️ 3. Adaptación Futura a Tiendanube Esta landing page está maquetada utilizando estándares limpios de HTML, CSS modular y JS. Para integrarla o clonar el diseño dentro de Tiendanube en el futuro: 1. **Edición CSS en Tiendanube**: Podés copiar las reglas de `styles.css` en la sección de *Edición de CSS avanzado* del panel de Tiendanube. 2. **Plantilla Personalizada (FTP / Layout)**: Podés asociar las clases `.product-card`, `.price-previous`, `.price-current` y `.btn-gold` a las variables de Liquid de Tiendanube (`{{ product.name }}`, `{{ product.price | price_format }}`, etc.).
